# Nabi Stacks

Mod para Minecraft Fabric que amplía los stacks hasta **500 ítems**.

## Objetivo de v1
- Límite configurable para inventario del jugador.
- Límite configurable para almacenamiento.
- Soporte experimental para objetos normalmente no stackeables cuando coinciden componentes y durabilidad.
- Pantalla de configuración en cliente.

## Target
- Minecraft Java 26.3
- Fabric Loader 0.19.5
- Fabric API 0.161.0+26.3
- Java 25

La compilación automática vive en GitHub Actions y genera el JAR como artifact.
